# Mimu's Birthday

A birthday surprise for Pooja (Mimu): a gift to open, a poem, photo chapters, our song and a candle to blow out.

Plain HTML, no build step. Open `index.html` or deploy the folder as a static site.

- `index.html`: the whole page
- `img/`: photos
- `audio/`: Tum Se Hi (background) and the Sasural Genda Phool chorus (plays on "Jhoom!")

The site asks search engines not to index it.
